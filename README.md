# Phosphor releases

Installers and the update feed for Phosphor, a desktop workspace for editing short videos with Codex or Claude Code.

Download the installer for your computer from [Releases](https://github.com/elebumm/phosphor-releases/releases):

- **Mac with Apple silicon:** `Phosphor-X.Y.Z-mac-arm64.dmg`
- **Intel Mac:** `Phosphor-X.Y.Z-mac-x64.dmg`
- **Windows (64-bit):** `Phosphor-X.Y.Z-win-x64-setup.exe`

Phosphor needs macOS 13 or later, or 64-bit Windows. It does not install Python 3.11+, FFmpeg, the Codex or Claude Code CLI, or editing apps; its readiness panel shows what is missing.

Installed copies of Phosphor check this repository for new versions. The source code is not published here.
